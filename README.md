# DriveSphere 🚗

DriveSphere is a modern car rental web application where users can explore, book, and manage rental cars easily with a smooth and responsive experience.

## 🌐 Live Website

Client Side Live Link: https://drivesphare.vercel.app/

---

## ✨ Features

- Browse available rental cars with detailed information
- Secure user authentication and authorization system
- Add, update, and manage car listings dynamically
- Responsive UI optimized for mobile, tablet, and desktop devices
- Real-time booking management and availability tracking
- Modern and clean user interface with smooth user experience
- Search and filter cars based on categories and preferences

---

## 🛠️ Technologies Used

- Next.js
- Hero UI
- Tailwind CSS
- MongoDB
- Express.js
- Better Auth 

---

## 📦 Installation

```bash
git clone <your-repository-url>
cd drivesphere
npm install
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env.local` file and add:

```env
NEXT_PUBLIC_API_URL=your_api_url
NEXT_PUBLIC_FIREBASE_API_KEY=your_key
```
